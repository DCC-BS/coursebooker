# Coursebooker API

This API provides CRUD operations for managing courses within the Coursebook application. It leverages Nuxt.js for the server-side framework and Drizzle ORM with SQLite for data management.

## Project Structure

The Coursebook project follows a structured approach to organize its codebase, particularly for the server-side API.

**Key Server-Side Directories:**

*   `server/api/`: This directory contains all the API route definitions.
    *   `courses/`: Holds all endpoints related to course management. Each HTTP method (GET, POST, etc.) for a given route is typically in its own file (e.g., `index.get.ts`, `[id].patch.ts`).
    *   `users/`: Contains endpoints for user management.
    *   `auth/`: Manages authentication-related routes.
*   `server/models/`: Houses data models that often represent the application's business logic or data structures, sometimes abstracting the raw database schema.
*   `server/plugins/`: Contains Nuxt server plugins. The `migrateDb.ts` plugin, for instance, handles automatic database migrations on application startup.
*   `server/utils/`: Includes utility functions and helper modules used across various parts of the server-side code (e.g., `mail.utils.ts` for email functionalities, `getUserSession.utils.ts` for session management).
*   `drizzle/`: This directory is auto-generated by Drizzle. It contains:
    *   SQL migration files (e.g., `0000_wide_pepper_potts.sql`).
    *   A `meta/` subdirectory with snapshots and journaling information about the migration history.
*   `shared/`: Contains code intended to be shared between the server and client (if applicable), such as TypeScript types and schema definitions. This helps maintain consistency across the application.
    *   `models/`: Shared data models.
    *   `schema/`: Shared Drizzle schema definitions, useful for type safety on the client if needed.

This structure promotes separation of concerns, making the codebase more maintainable and scalable.

## Endpoints

The API endpoints are defined below with their respective input and output schemas.

### `/api/courses`
*   **GET**
    *   **Description:** Retrieve a list of all courses, with optional filtering.
    *   **Query Parameters:**
        *   `from` (date, optional): Filter courses from this date (ISO 8601 format).
        *   `to` (date, optional): Filter courses until this date (ISO 8601 format).
        *   `organizer` (string, optional): Filter by organizer name.
        *   `search` (string, optional): Search in course title and description.
        *   `sort` (enum, optional): Sort order - `asc` or `desc`. Default is `asc`.
        *   `offset` (number, optional): Offset for pagination. Default is `0`.
        *   `limit` (number, optional): Number of courses per page. Default is `10`.
    *   **Responses:**
        *   `200 OK`: An array of `Course` objects.
            ```json
            [
              {
                "id": "string",
                "title": "string",
                "description": "string",
                "type": "course" | "event",
                "organizer_name": "string",
                "organizer_mail": "string",
                "form_schema": "string | null",
                "sessions": [
                  {
                    "id": "string",
                    "courseId": "string",
                    "location": "string | null",
                    "teams_link": "string | null",
                    "ics_url": "string | null",
                    "lessons": [
                      {
                        "id": "string",
                        "sessionId": "string",
                        "start": "date (ISO 8601 string)",
                        "end": "date (ISO 8601 string)"
                      }
                    ],
                    "registrations": [
                      {
                        "user_email": "string",
                        "session_id": "string",
                        "additional_data": "string | null"
                      }
                    ]
                  }
                ]
              }
            ]
            ```
*   **POST**
    *   **Description:** Create a new course. Requires admin privileges.
    *   **Request Body:** `CreateCourse` schema.
        ```json
        {
          "title": "string",
          "description": "string",
          "type": "course" | "event",
          "organizer_name": "string",
          "organizer_mail": "string (email)",
          "form_schema": "string | null"
        }
        ```
    *   **Responses:**
        *   `200 OK`: The newly created `Course` object.

### `/api/courses/{id}`
*   **GET**
    *   **Description:** Retrieve a specific course by its ID.
    *   **Parameters:**
        *   `id` (path, required, string): The ID of the course.
    *   **Responses:**
        *   `200 OK`: A `Course` object.
        *   `404 Not Found`: If the course is not found.
*   **PATCH**
    *   **Description:** Partially update an existing course. Requires admin privileges.
    *   **Parameters:**
        *   `id` (path, required, string): The ID of the course.
    *   **Request Body:** `UpdateCourse` schema (partial `CreateCourse`).
        ```json
        {
          "title": "string (optional)",
          "description": "string (optional)",
          "type": "course | event (optional)",
          "organizer_name": "string (optional)",
          "organizer_mail": "string (email, optional)",
          "form_schema": "string | null (optional)"
        }
        ```
    *   **Responses:**
        *   `200 OK`: The updated `Course` object.
        *   `404 Not Found`: If the course is not found.
*   **DELETE**
    *   **Description:** Delete a course. Requires admin privileges.
    *   **Parameters:**
        *   `id` (path, required, string): The ID of the course.
    *   **Responses:**
        *   `200 OK`: The deleted `Course` object.
        *   `404 Not Found`: If the course is not found.

### `/api/courses/{id}/sessions`
*   **GET**
    *   **Description:** Retrieve all sessions for a specific course.
    *   **Parameters:**
        *   `id` (path, required, string): The ID of the course.
    *   **Responses:**
        *   `200 OK`: An array of `Session` objects (without `ics_file`).
            ```json
            [
              {
                "id": "string",
                "courseId": "string",
                "location": "string | null",
                "teams_link": "string | null",
                "ics_url": "string | null",
                "lessons": [
                  {
                    "id": "string",
                    "sessionId": "string",
                    "start": "date (ISO 8601 string)",
                    "end": "date (ISO 8601 string)"
                  }
                ],
                "registrations": [
                  {
                    "user_email": "string",
                    "session_id": "string",
                    "additional_data": "string | null"
                  }
                ]
              }
            ]
            ```
*   **POST**
    *   **Description:** Create a new session for a course. Requires admin privileges. Expects `multipart/form-data`.
    *   **Parameters:**
        *   `id` (path, required, string): The ID of the course.
    *   **Request Body (`multipart/form-data`):**
        *   `location` (string, optional): The location of the session.
        *   `teams_link` (string, optional): The Microsoft Teams link for the session.
        *   `ics_file` (file, optional): The ICS calendar file for the session.
    *   **Responses:**
        *   `200 OK`: The newly created `Session` object.

### `/api/courses/{id}/sessions/{sessionId}`
*   **GET**
    *   **Description:** Retrieve a specific session.
    *   **Parameters:**
        *   `id` (path, required, string): The ID of the course.
        *   `sessionId` (path, required, string): The ID of the session.
    *   **Responses:**
        *   `200 OK`: A `Session` object (includes `ics_file` as a buffer).
        *   `404 Not Found`: If the session is not found.
*   **PATCH**
    *   **Description:** Partially update an existing session. Requires admin privileges. Expects `multipart/form-data`.
    *   **Parameters:**
        *   `id` (path, required, string): The ID of the course.
        *   `sessionId` (path, required, string): The ID of the session.
    *   **Request Body (`multipart/form-data`):**
        *   `location` (string, optional): The location of the session.
        *   `teams_link` (string, optional): The Microsoft Teams link for the session.
        *   `ics_file` (file, optional): The ICS calendar file for the session.
    *   **Responses:**
        *   `200 OK`: (Empty response on success)
        *   `404 Not Found`: If the session is not found.
*   **DELETE**
    *   **Description:** Delete a session. Requires admin privileges.
    *   **Parameters:**
        *   `id` (path, required, string): The ID of the course.
        *   `sessionId` (path, required, string): The ID of the session.
    *   **Responses:**
        *   `200 OK`: The deleted `Session` object.
        *   `404 Not Found`: If the session is not found.

### `/api/courses/{id}/sessions/{sessionId}/ics`
*   **GET**
    *   **Description:** Download the ICS calendar file for a session.
    *   **Parameters:**
        *   `id` (path, required, string): The ID of the course.
        *   `sessionId` (path, required, string): The ID of the session.
    *   **Responses:**
        *   `200 OK`: The ICS file content (`text/calendar`).
        *   `404 Not Found`: If the session or its ICS file is not found.
*   **DELETE**
    *   **Description:** Delete the ICS calendar file associated with a session. Requires admin privileges.
    *   **Parameters:**
        *   `id` (path, required, string): The ID of the course.
        *   `sessionId` (path, required, string): The ID of the session.
    *   **Responses:**
        *   `200 OK`: The session object with `ics_file` and `ics_url` set to null.
        *   `404 Not Found`: If the session is not found.

### `/api/courses/{id}/sessions/{sessionId}/lessons/{lessonId}`

    *   **Parameters:**

    *   **Responses:**

### `/api/courses/{id}/sessions/{sessionId}/register`
*   **POST**
    *   **Description:** Register a user for a session. Admins can register any user; non-admins can only register themselves.
    *   **Parameters:**
        *   `id` (path, required, string): The ID of the course.
        *   `sessionId` (path, required, string): The ID of the session.
    *   **Request Body:**
        ```json
        {
          "userEmail": "string (email or 'me' for authenticated user)",
          "additionalData": "string (optional, max 1000 chars)"
        }
        ```
    *   **Responses:**
        *   `200 OK`: (Empty response on success)
        *   `400 Bad Request`: If course/session ID is missing or invalid input.
        *   `401 Unauthorized`: If 'me' is used by an unauthenticated user.
        *   `404 Not Found`: If course or session is not found.
        *   `409 Conflict`: If user is already registered.

### `/api/courses/{id}/sessions/{sessionId}/unregister`
*   **POST**
    *   **Description:** Unregister a user from a session. Admins can unregister any user; non-admins can only unregister themselves.
    *   **Parameters:**
        *   `id` (path, required, string): The ID of the course.
        *   `sessionId` (path, required, string): The ID of the session.
    *   **Request Body:**
        ```json
        {
          "userEmail": "string (email or 'me' for authenticated user)"
        }
        ```
    *   **Responses:**
        *   `200 OK`: (Empty response on success)
        *   `400 Bad Request`: If course/session ID is missing.
        *   `401 Unauthorized`: If 'me' is used by an unauthenticated user.
        *   `404 Not Found`: If course/session is not found or user is not registered.

## Data Schemas

### `Course`
```typescript
{
  id: string; // Primary key
  title: string;
  description: string;
  type: "course" | "event";
  organizer_name: string;
  organizer_mail: string; // Valid email
  form_schema: string | null;
  sessions: Session[]; // Array of associated sessions
}
```

### `Session`
```typescript
{
  id: string; // Primary key
  courseId: string; // Foreign key to Course
  location: string | null;
  teams_link: string | null;
  ics_file: Buffer | null; // Binary data for ICS file
  ics_url: string | null; // URL to download ICS file
  lessons: Lesson[]; // Array of associated lessons
  registrations: UserToSession[]; // Array of user registrations
}
```

### `Lesson`
```typescript
{
  id: string; // Primary key
  sessionId: string; // Foreign key to Session
  start: Date; // ISO 8601 timestamp
  end: Date; // ISO 8601 timestamp
}
```

### `User`
```typescript
{
  email: string; // Primary key, valid email
  isAdmin: boolean; // Default: false
  registrations: UserToSession[]; // Array of session registrations
}
```

### `UserToSession` (Join Table for Registrations)
```typescript
{
  user_email: string; // Foreign key to User
  session_id: string; // Foreign key to Session
  additional_data: string | null; // Optional additional registration data
}
```

### Input Schemas for Creation/Update

*   `CreateCourse`: Omit<Course, "id" | "sessions">
*   `UpdateCourse`: Partial<CreateCourse>
*   `CreateSession`: Omit<Session, "id" | "lessons" | "registrations"> & { ics_file?: Blob };
*   `UpdateSession`: Partial<CreateSession>;
*   `CreateLesson`: Omit<Lesson, "id">;
*   `UpdateLesson`: Partial<CreateLesson>;

## Validation Rules

- **Date:** Must be in YYYY-MM-DD format for query params, ISO 8601 for body.
- **Time:** Must be in HH:MM format (24-hour) for query params, ISO 8601 for body.
- **Duration:** Must be a positive number (hours).
- **Email:** Must be a valid email format.
- **Uniqueness:** No two courses can have the same name, date, and time.

## Error Responses

- `400 Bad Request`: Invalid input data, missing required parameters.
- `401 Unauthorized`: Authentication required or insufficient privileges.
- `404 Not Found`: Resource (Course, Session, Lesson, User) not found.
- `409 Conflict`: Resource already exists (e.g., user email, course name/date/time).
- `500 Internal Server Error`: Server error.

## Data Storage

Uses SQLite database for persistent storage. The database file is typically located at `./data/courses.db` (this can be configured via environment variables).

**Database Configuration:**
- **Default:** SQLite database.
- **Environment Variables:**
  - `DATABASE_TYPE`: Database type (e.g., `sqlite`, `postgresql`, `mysql`, `memory` - though SQLite is the primary supported type for this project).
  - `DATABASE_PATH`: Path to the SQLite database file.

**Database Features:**
- **Schema Management:** Automatic schema creation and migration via Drizzle ORM and the Nuxt plugin (`server/plugins/migrateDb.ts`).
- **Data Integrity:** Enforces schema constraints, unique keys, and data types.
- **Timestamps:** Records include `created_at` and `updated_at` timestamps for tracking changes.

**Future Database Support:**
The architecture, facilitated by Drizzle ORM, theoretically supports switching to other database backends like PostgreSQL or MySQL by updating the connection configuration and potentially adjusting schema definitions for compatibility. However, the project is primarily designed and configured for SQLite.
